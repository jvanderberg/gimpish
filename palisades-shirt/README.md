# Palisades Park Trailblazers shirt

Layered Gimpish reconstruction of the original screenprinted tee in `shirt.jpeg`.
The editable document is `scene.json`.

## Edit in Gimpish

Open `scene.json` in the Gimpish desktop app. The composition keeps each recovered
element independently editable:

- hidden original-shirt reference (`shirt.jpeg`)
- traced tree (`tree-layer.svg`)
- “hug a tree” lettering (`hug-a-tree-layer.svg`)
- arched “Palisades Park” type (`palisades-park-arched-layer.svg`)
- bottom “Trailblazers” type (`trailblazers-bottom-layer.svg`)
- “MSR” initials as live American Typewriter text

The canvas is transparent and the visible artwork uses cream `#F2E8D5`. The export
screen can render the SVG-backed composition directly at the print presets,
including 3600×2700 and 4800×3600 PNG.

## Reconstruction provenance

The remaining SVG, PBM, PNG, and Python files preserve the tracing and type-fitting
work used to recover the artwork from the shirt photograph. They are source
provenance, not the editing workflow; continue design changes in `scene.json`.

The original typeface was identified as American Typewriter Semibold. The
ascender-to-x-height ratio matches the print, and the slightly heavier appearance
is consistent with screenprint ink gain.
